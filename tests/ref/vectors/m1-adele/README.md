# tests/ref/vectors/m1-adele: the vector oracle for `adf_adele` and `adf_cadele`

Generated by `lanes/m1-adele/gen_adele_vectors.py` (seed 20260928) from
`tests/ref/adfref/adele_ref.py`, which is written from `include/adelefeld/adele.h` and from
`docs/SPEC.md` 4.1, 4.3, 4.5, `docs/conventions.md` 5.5 and `docs/proofs/precision.md`
Propositions 1, 2 and 6. Regenerate with

    python3 lanes/m1-adele/gen_adele_vectors.py

The C tests `tests/test_adele.c` and `tests/test_cadele.c` read these files with
`tests/support/jsonl.h`; they do not read the Python reference. A rational is
`{"num": n, "den": d}` in lowest terms with `den > 0`. A finite ball is the canonical triple
`{"A": a, "H": h, "d": d}` of `adf_fball` (tests/ref/README.md). A real interval is
`{"lo": r, "hi": r}`, a complex box is `{"re": interval, "im": interval}`.

## `adele_ops.jsonl`

One record per operation:

    {"op": "add", "prec": 53,
     "a": {"re": interval, "fin": ball},
     "b": {"re": interval, "fin": ball},          (absent for neg and the scale operations)
     "q": rational,                                (only for add_rat, mul_rat, div_rat)
     "result_fin": ball,                           the exact finite result set
     "result_re": interval,                        the interval hull of the true real result
     "witness": [ {"a_re": r, "a_fin": r, "b_re": r, "b_fin": r,
                   "re_image": r, "fin_image": r}, ... ]}

`op` is one of `add`, `sub`, `mul`, `neg`, `add_rat`, `mul_rat`, `div_rat`. A witness names a
rational point `a_re` in the first real interval, a rational point `a_fin` of the first finite
ball, and likewise for the second operand when there is one, together with the exact image
point. The C result must contain the image in each coordinate. The real coordinate of the C
input is an arb that contains the interval `re`; the finite coordinate is built from the exact
triple. The finite result must be identical to the result of the `adf_fball` function alone and
must not depend on `prec`. For the real coordinate the test also checks that both ends of
`result_re` lie in the output.

`cadele_ops.jsonl` has the same schema, with the complex coordinate `{"re": interval,
"im": interval}` in place of the real one, witnesses `a_im`, `b_im`, `im_image`, and no
`result_re`. The enclosing box of a complex product is not unique, so the record does not claim
one; the point witnesses are the oracle.

## `set_rat.jsonl`

    {"q": rational, "prec": p, "exact": true|false}

`exact` is true when the ball of `q` at `p` bits is exact: `q = 0`, or `q` is dyadic and its odd
mantissa has at most `p` bits. The C test checks containment of `q` in the real (or complex)
coordinate, exactness of the finite coordinate, and the flag.

## Coverage

`adele_ops.jsonl` and `cadele_ops.jsonl` hold random operands for each operation at the
precisions 2, 10, 53, 64, 128 and 4096, four witnesses each, and the finite examples of the
table in `docs/SPEC.md` 4.3. `set_rat.jsonl` holds `1/3`, `-1/3`, `0`, negative rationals and
huge rationals of about 4096 bits at the precisions 2, 10, 53, 64 and 4096, and dyadic cases
that fit or do not fit the requested precision.
