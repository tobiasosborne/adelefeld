# Slice 3.2-a: the adelic additive character

This file states what src/psi.c adds to docs/api-3.md sections 3.1 to 3.3 and Q4.
It covers five calls. Class characters, local characters, adf_char, and Gauss sums remain later slices.
Inputs and outputs are initialized. Inputs are canonical. No output overlaps an input or its members.
The signatures have different output and input types, so there is no permitted in-place combination.
Every ordinary output is untouched on failure. Temporary values are cleared on every exit.

## Definition and sign

Conventions 6.1:844 fixes the definition implemented here:

    psi_p(x) = E(fp_p(x)), psi_inf(x) = E(-x), psi(x) = psi_inf(x_inf) product_p psi_p(x_p).

E(t) means exp(2 pi i t). The source is refs/src/tate-poonen/notes.txt:693-700.
Its real factor has a minus sign; its prime factors have a plus sign. Lines 733-740 discuss
the transform convention. CV-54 at conventions:852-874 conjugates psi in the transform only.

At (0 ; 1/3), the 3-primary fractional part is 1/3 and every other fractional part is zero.
The real factor is E(-0)=1. Thus psi is E(1/3)=-1/2+i sqrt(3)/2. Its imaginary part is positive.
For a rational a, analysis.md Lemma 2:87-88 gives psi_f(a)=E(a).
That step proves triviality on diagonal Q. Descent to A/Q is the separate step :92-94.

For x=(m +/- r ; a + N Zhat), put b=(a-m) mod 1 and B=denominator(N), with denominator(0)=1.
Lemma 2:78-91 gives the exact image as the union of E([b+k/B-r,b+k/B+r]), 0<=k<B.
Q4:593-628 gives the four extrema and the singleton criterion. No prime factorization is needed.

Check: tests/test_psi.c sign comment, golden(), vectors(), exact_and_additivity().
All 17 golden rows run; the two malformed rows test the existing finite-ball parser.
The vectors contain 80 stored dyadic real balls, four rational distances each, and 40 points each.
They are generated by lanes/q-slice3/gen_vectors.py from proto/quotient3_checks.py.

## Exact finite phase

adf_fball_psi_tate_phase(theta,x) returns OK and writes a reduced theta in [0,1) exactly when N is
an integer, including zero. It returns NOT_DETERMINED otherwise, after resource preflight.
On OK theta is a mod 1. Lemma 2:89-91 shows why integer N leaves just this value.
For noninteger N the B distinct roots show why selecting one value would be wrong.

The code first bounds raw A,H,d. Raw local H bounds the CRT representative before reconstruction.
The centre accessor forms the canonical global centre. The radius accessor cancels raw H/d.
Testing its reduced denominator handles a local representation whose raw d is greater than one.
Modular reduction replaces the numerator by its residue and canonicalizes the fraction.
Only then does the code swap theta with its temporary.

Cost: one canonical centre, one radius reduction, and a rational modular reduction.
For global storage this is integer division and gcd work on the stored bit sizes.
For local storage the centre adds CRT work for the context's blocks. No context is changed.
Memory is linear in the bounded integer sizes plus the existing centre accessor's CRT temporaries.

Check: golden(), vectors(), edges(); local raw d>1 with integral canonical radius passes.
Negative and 2000-bit centres, finite radius zero, integral and fractional radii all run.

## Exact adele phase

adf_adele_psi_tate_phase(theta,x) additionally requires r=0. It returns NOT_DETERMINED for a real
arc or a finite family. Q4 step 7 proves both directions. On OK theta=(a-m) mod 1.

The code reads the stored midpoint and mag radius as exact dyadic rationals after exponent and bit checks.
It reduces both a and m modulo one before exact subtraction. This preserves the character and prevents
a large integer part from obscuring a small angle. A projected subtraction check precedes the operation.
The singleton tests follow the exact-work checks. The final swap is the only output write.

Cost: finite extraction, exact dyadic conversion, bounded rational subtraction, division, and gcds.
The memory bound is linear in the intermediate rational bit sizes.

Check: 500 exact dyadic diagonal rationals have theta=0 and exact numerical psi=1.
There are also 200 exact angle-additivity pairs. An independently rounded diagonal 1/3 is a ball,
so its exact getter returns NOT_DETERMINED while its default character contains 1.
An adele cannot store a non-dyadic exact real rational or the correlation of that diagonal point.

## Numerical phase

adf_phase_get_acb(z,theta,prec) evaluates E(theta). Canonical theta in [0,1) is a precondition.
The code checks it under INV. The exact phases 0,1/4,1/2,3/4 give exact 1,i,-1,-i.
Every other phase is evaluated with arb_sin_cos_pi_fmpq on twice the rational angle.
The argument contract and reduction are refs/src/flint-3.0.1/arb.rst:1125-1139.

Put p=max(prec,2) and epsilon=2^-p. Working precision starts at min(p+32,ADF_REAL_PREC_MAX).
The enclosure guarantee is refs/src/flint-3.0.1/arb.rst:6-12, read alongside the trig contract above.
Each coordinate must have radius <=epsilon/2, hence width <=epsilon.
Working precision doubles until certification succeeds or reaches the cap.
Failure to certify returns NOT_DETERMINED. Rational size or doubling overflow of the stated bit bound
returns LIMIT. The precision cap is checked first, including before the INV precondition check.

Certified endpoints are clipped to [-1,1]. This retains the exact sine and cosine.
Each coordinate is then rounded by the kernel below. Only the completed acb is swapped into z.
Cost: one bounded rational doubling and at most logarithmically many trig attempts up to the cap.
The cardinal branch has constant output size. Noncardinal trig cost depends on argument size and precision.

Check: 100 rational phases at p=2,20,53,128; enclosure and endpoint excess, not mere overlap.
Cardinal phases also run at the cap. A noncardinal phase 1/3 reaches certificate failure at the cap.

## Default and strict adele character

adf_adele_psi_tate(z,x,prec) encloses every point of the exact image, including fractional finite radius.
It computes Q4's four exact distances without enumerating the roots:

    d(t)=max(0,dist(B(t-b),Z)/B-r), t=0,1/2,1/4,3/4.

The corresponding hull is

    real: [-cos(2 pi d(1/2)),cos(2 pi d(0))],
    imag: [-cos(2 pi d(3/4)),cos(2 pi d(1/4))].

The code reduces the scaled difference modulo one, takes min(u,1-u), divides by B, subtracts r,
and clips negative distance to zero. Q4 steps 1 to 3 prove that this includes interior extrema as well
as arc endpoints. Exact distances 0,1/4,1/2 are handled without numerical uncertainty.
Each other cosine is certified with the same width criterion and retries as the numerical phase call.
An upper bound for cos(d) is also an outward lower bound after negation for -cos(d).
Four upper bounds therefore suffice. The two completed coordinates are committed together.

adf_adele_psi_tate_strict(z,x,prec) uses the same hull, but rejects B>1 with NOT_DETERMINED
before any trig evaluation. CV-59, conventions:881-887, specifies this finite-radius certificate.
It permits r>0. This certificate is weaker than a singleton image and differs from the phase getter.
Precision and exact-work preflight take precedence. The default and strict outputs agree when B=1.

Cost: finite extraction, constant-count rational modular arithmetic, and four certified cosine evaluations.
It depends on log(B), not on B roots. Memory is linear in bounded rational sizes and working precision.
The strict branch deliberately completes the exact distance preflight before rejecting ambiguity.

Check: 3200 vector points, with exact input membership checked; containment at four output precisions.
Each of 640 coordinate hull comparisons asserts the section 3.3 excess bound at both endpoints.
E3 has a line hull and rejects the universal unit square. A 2001-bit order runs without enumeration.
There are 200 ball-additivity pairs, with 40 sampled products each in both enclosing rectangles.
The driver commands psi and psi_strict and tests/julia/psi.jl exercise the public calls.

## Coordinate rounding and excess

For certified dyadic endpoints l<=h in [-1,1], compute their exact midpoint c.
Round it to nearest-even at p bits to get m. Put eta=abs(m-c) and d=max(m-l,h-m).
Then d=(h-l)/2+eta, even when m is outside [l,h]. If d=0 store radius zero.
Otherwise round d upward to 30 bits and take its least 30-bit successor rho.
Construct mag directly from the normalized mantissa and exponent; this preserves that chosen kernel.
General mag conversions may add extra ulps, as refs/src/flint-3.0.1/mag.rst:6-15 explicitly permits.
Correct arf rounding is sourced at arf.rst:24-35. Its exact rational conversion is at :310-315.

Since rho>=d, both endpoints are enclosed. Q1 gives rho-d<=2^-28*d.
Each certified endpoint is at most epsilon outside its exact extremum. Rounding m adds at most epsilon
on [-1,1]. Thus d<=W/2+2*epsilon, where W is the true coordinate width.
The endpoint excess is at most the specified bound

    4*epsilon + 2^-28*(W/2+2*epsilon).

This allowance tends to zero for a singleton. The mag contribution for a genuine arc may remain.
The tests separately assert enclosure and this bound. They do not accept an arbitrary containing square.

Check: hullcheck() covers every vector hull at p=2,20,53,128 and all numerical phase coordinates.

## Limits, statuses, and decisions

Numerical calls return LIMIT first for prec>ADF_REAL_PREC_MAX=2097152.
Exact conversion rejects absolute ARF exponent above ADF_QCLASS_EXP_MAX=1048576.
Numerators, denominators, raw finite fields, and projected rational products are bounded by
ADF_QCLASS_BITS_MAX=2097152 bits. The checks precede exponent-sized conversion or products.
Conservative projected carry and cross-product bounds may reject arithmetic whose reduced answer fits.
This is an explicit implementation bound, not a mathematical undecidability claim.
Exact phase getters return OK, NOT_DETERMINED, or LIMIT on canonical inputs.
Numerical calls return those three statuses. No call here needs UNSUPPORTED.
These calls use the character status row, conventions 3.2:223, including repair R8 of the design.

The design is silent about invalid raw real balls and about invalid theta outside its precondition.
Decision: invalid theta is undefined in a normal build and aborts under INV. The alternative would add
DOMAIN and validation to the public contract. This slice keeps the design's canonical-input contract.
A nonfinite raw adele real component returns DOMAIN in a normal build as a courtesy; under INV it aborts.
This follows the existing typed adele precondition and the localfactor.h raw-ball courtesy.
All such normal-build failures leave outputs untouched. Precision LIMIT remains first under INV too.

Decision: preflight uses stored fields and conservative projected products. An alternative is to factor
common divisors before every bound, accepting more cancellations at additional cost and complexity.
The present reading agrees with the preceding qclass slice and is documented rather than hidden.
The raw local d is used only after reducing H/d for the finite integrality test.

Design wording finding: api-3.md:523-524 says the proof uses l<=m<=h. That relation need not hold for
a rounded midpoint: l=h=1/3 and p=2 give m=3/8. The enclosure and excess conclusions remain valid.
The absolute-error calculation above supplies the missing justification without that relation.
No specification or design source file is changed.

Check: edges(), INV child abort tests, failure snapshots of both object bytes and copied values.
The only pending source attribution is Tate's thesis section 2.2, already marked in SPEC:421-422.
The on-disk Poonen exposition independently supplies every sign used here.

## Finding against the specification's decision annotation

SPEC:944, N-D21's last sentence, says that 0 mod 1/2 is not inside A_f.
This contradicts the restricted-product definition quoted from refs/src/milne-cft/CFT.txt:9373-9376.
The ball means (1/2) Zhat under SPEC:74-77. A direct proof is:

1. Write any point as x_p=z_p/2, with z_p in Z_p for every prime p.
2. For p other than 2, 2 is a p-adic unit, so x_p is in Z_p.
3. The 2-component is in Q_2. Only this one component may fail to be integral.
4. Thus every point satisfies the restricted-product condition, and (1/2) Zhat is a subset of A_f.

More generally the denominators of rational a and N contain only finitely many prime factors.
Outside those primes, a+N Z_p is contained in Z_p, so a+N Zhat is contained in A_f.
The code follows this meaning and the finite phase families of SPEC 6 and analysis Lemma 2.
The finding concerns the annotation, not the additive-character formula or its ball-image statement.
