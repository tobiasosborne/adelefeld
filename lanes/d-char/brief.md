## What `docs/api-3c.md` contains

1. **The type.** Its predicate (5.13: primitive, `q` the conductor, `parity` consistent, `s` finite), the
   init value, set statement (which function on the idele class group a value means), `is_canonical`,
   layout queries, the missing typed declarations of `text.h` (reader and printer of `char(...)`; conventions
   11.3 for `s`) and `dump.h` (body `char`: does conventions 10 define it? if not, propose the body in the
   style of the others and mark it a decision), as `docs/api-3.md` 2.5 did for the class.
2. **Constructors and accessors.** From `(q, n)` with lowering to the primitive character (what status for
   `gcd(n, q) > 1`, `q = 0`, `n = 0`, `q >= 2^64` through `ulong`; where the lowered label comes from); from
   `(q, n, s)`; `set_s`; getters for conductor, label, parity, order; `conj` (the label `n^-1 mod q`:
   5.13 probed it, prove it or cite the source); product of two characters (the lcm of the conductors,
   then lowering: in scope or deferred? say which and why).
3. **Evaluation.** `chi(a)` for an integer `a` (exact phase `fmpq` through the exponent, or the zero branch
   for non-units, as `api-3.md` 3.4 says: which output type carries "zero or a phase"?); the value `t^s chi(u')`
   on an `adf_idclass` and on an `adf_idele` (through `adf_idclass_set_idele`), default and `_strict`: the
   enclosure of all values when the conductor does not divide `N` (the set of values is the image of a coset
   of `U(N)` under `chi`: a finite set of roots of unity; its rectangular hull by the method of `api-3.md` Q4;
   prove the extrema), `NOT_DETERMINED` for strict; `t^s` by `arb_pow_arb`/`acb_pow` with the status rule for
   `t` containing 0; the real sign `u' = sign(x_inf) u` (ideles P15): where it enters; statuses, outputs
   untouched on failure, aliasing, cost, `prec` cap first.
4. **Gauss sum and root number (3.4).** `adf_char_gauss_sum(acb_t tau, const adf_char_t chi, slong prec)` and
   `adf_char_root_number`: the algorithm (the direct sum of `C` exact phases through `adf_phase_get_acb`, with
   the error bound of `C` additions; the cost `O(C)` trig evaluations and a `LIMIT` bound on `C`: state it and
   say what FLINT's factorisation method would buy later), the identities to test (`|tau|^2 = C`,
   `tau(chi) tau(conj chi) = (-1)^e C`, `W W_conj = 1`, `W = 1` for the 8 real characters of the goldens as
   finite checks), the comparison with `acb_dirichlet_gauss_sum` (overlap of balls, both signs settled by the
   source lines), and the 17 golden rows.
5. **Statements to add to `analysis.md`** (numbered steps, proofs written out): the set of values of `chi` on
   a unit coset `c U(N)` when the conductor `C` does not divide `N` (it is `chi(c)` times the image of
   `U(N) -> (Z/C)^x`, a subgroup of the roots of unity of order dividing `ord(chi)`: compute it exactly); the
   bound of the direct Gauss sum; the lowering of a label.
6. **Acceptance tests and faults**: per function what a test must check so that it fails for a wrong
   implementation (exact small cases from the oracle; the 17 golden rows; the PLAN tests of rows 3.3, 3.4);
   six faults to plant per work package (the sign of the Gauss sum; `n mod f` as the lowered label; the parity
   from `n` instead of the character; the zero branch returning the phase 0; strict writing on ambiguity; the
   hull from end points only).
7. **Decisions for TJO**: few and real; a decision SPEC or the conventions already take is cited, not asked.
8. **Thin slices**: two or three, each the smallest piece a user can call (driver `adf` command, say `adf
   char 'char(q=5, n=2, s=(0) + (0)*i)'`, `adf gauss ...`, and a Julia `ccall`), with its functions, its oracle
   group in `proto/char_checks.py` and the decisions it needs. The first slice (the type, text, `chi(a)`,
   Gauss sum, the goldens) should fit one lane of about an hour.
9. **Findings** against SPEC, PLAN, conventions, proofs, goldens, each with the counterexample.

`proto/char_checks.py` must run: `timeout 120 python3 proto/char_checks.py` prints each group with its counts
and ends with the number of checks; every example of the design is computed by it. It provides the oracle
functions the implementation lanes will use: `lower(q, n)` giving the primitive `(C, n', parity, order)`;
`chi_exponent(C, n, a)` giving `k` with `chi(a) = E(k/order)` or `None` on a non-unit; `coset_values(C, n, c, N)`
giving the exact set of phases; `gauss(C, n)` as a complex number with its error bound.
